Estado del sistema

Aplicación web de prueba desplegada en EC2

Sistema básico de reservas para evaluación de capacidad

Esta página simula una aplicación web sencilla donde varios usuarios consultan servicios disponibles al mismo tiempo. Su objetivo es servir como destino para una prueba de carga controlada con k6.

Consulta de servicios

Los usuarios pueden revisar servicios disponibles, horarios y disponibilidad.

Reservas iniciales

El sistema representa una carga inicial típica antes de pasar a producción.

Evaluación con k6

El endpoint /api/test permite medir latencia, errores y degradación.

Propósito de la aplicación

Esta aplicación no busca resolver un problema empresarial completo. Su propósito es ofrecer una página web estable y medible para analizar cómo una instancia EC2 de bajo costo responde ante diferentes niveles de usuarios concurrentes.
